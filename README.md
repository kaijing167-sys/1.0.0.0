# 青禾纪事 · 高中模拟器

以高中生活为背景的文字模拟游戏：选择人物和开局阶段，安排学习、休息、社交与周末生活，经历校园事件和考试，走向自己的青春结局。

**[点击在线试玩](https://kaijing167-sys.github.io/1.0.0.0/)** · [仓库](https://github.com/kaijing167-sys/1.0.0.0)

当前版本在原有高中旅程的玩法和界面上，融入四名人物、头像、班级选择、换班和统一进度存档。所有人物使用同一套 `game.js` 流程。本文按 2026 年 10 月 17 日已提交的功能整理。

## 如何开始

1. 打开试玩链接，在创建页面选择已录入人物，或创建自定义人物。
2. 选择开局阶段和班级，点击“开始游戏”。
3. 通过学习、休息、锻炼、社交等行动安排本周生活。
4. 游戏内点击“我的班级”查看分班或申请换班。
5. 在“设置 → 进度存档槽”保存、恢复或删除进度；也可导出 JSON 备份。

已有进度时会继续当前旅程。想更换人物，请先保存或导出进度，再使用“设置 → 重新开始”。

|---|---|---|---|
| 2班 | 物化生 | 尖子班 | 50 |
| 4班 | 物化生 | 普通班 | 50 |
| 7班 | 物化政 | 普通班 | 50 |
| 8班 | 物化地 | 普通班 | 50 |
| 11班 | 政史地 | 尖子班 | 50 |
| 13班 | 政史地 | 普通班 | 50 |
| 14班 | 史政生 | 普通班 | 30 |

开局可以选班，游戏过程中也可以换班。换班保留时间进度、科目能力和已有游戏状态；后续学习选项及考试计分按新班级选科调整。班级当前人数随玩家转入、转出变化，默认人数不是禁止转入的容量上限。

目前仅录入四名人物，其余名额显示为待补充，并未生成全部学生资料。后续新增人物需要同步人物数据和前端数据文件；新增班级还需要同步前后端班级配置。

## 成绩与成长规则

- 填写表中的语文、数学、英语按百分制乘以 **1.5**，换算为满分 **150**；保留小数。
- 物理、化学、生物、历史、政治、地理满分均为 **100**。
- 选择班级后，以语数外和该班三门选科组成六科基础能力，总上限 **750**。
- 考试仍保留原版的策略、压力、难度和随机发挥修正，因此考试结果不一定等于六科能力直接相加。
- 尚未选择具体班级的自定义人物继续使用原版综合文理科规则。

### 最新调整：每次小幅成长

| 入口 | 当前增长规则 |
|---|---|
| 普通学习 | 每次目标科目增加 **0.5** |
| 补课 | 目标科目增加最多 **0.5**；综合文理科收益分配后可能更低 |
| 剧情、周末等学科收益 | 单项正向增量最多 **0.5** |
| 魅力、体质、心态的效果加成 | 单项正向增量最多 **0.5** |

接近上限时，只增加剩余差值，例如语文从 149.8 增至 150，提示实际增加 0.2。小数会随进度保存。调整不会回退已有存档中的成绩；负向效果，以及体力、压力、心情、金钱和关系值等生活数值仍按各自规则变化。

## 原有玩法

- **四种开局**：高一开学、高二开学、高三开学、百日冲刺。
- **每周行动**：默认每周 4 次，安排学习、休息、锻炼和社交；设置中可调整节奏。
- **校园关系**：与李强、苏若云、林婉儿交流、培养羁绊和周末外出。这些剧情同学与可选的四名主角分别配置。
- **周末生活**：补课、自习、兼职、家庭活动、兴趣和外出。
- **事件与考试**：按日期推进校园剧情，经历阶段考试与高考。
- **成长与结局**：查看 10 项成就目标、旅程记录和最终结局。
- **显示与音乐**：支持大字体、紧凑布局、减少动态效果、背景音乐开关及本地音频替换。

## 存档：人物与进度统一保存

角色身份、当前班级、科目能力、日期、行动点、关系和事件记录都属于同一个旅程存档。

| 使用方式 | 自动保存 | 5个手动进度槽 | JSON导入导出 |
|---|---|---|---|
| GitHub Pages 在线版、普通静态服务器 | 当前浏览器 | 当前浏览器 | 支持 |
| FastAPI 的 `/play/` 页面 | 当前浏览器 | 后端数据库 | 支持 |

GitHub Pages 只发布静态网页，**不会运行 Python 后端**，在线试玩版没有账号或跨设备自动同步。

浏览器存档与访问来源绑定。更换浏览器、设备或清理站点数据前，请导出 JSON。数据库槽使用浏览器保存的匿名凭证识别归属；清除凭证也会失去原槽的访问入口，请保留备份。

当前统一旅程使用 `qinghe-game-v2` 保存自动进度。早期独立人物版本的数据不会被主动删除，但因玩法结构不同，不会自动转换为统一旅程。旧 `characters/index.html` 入口会跳转到当前首页。

## 本地运行

### 仅体验前端

下载或克隆仓库，在仓库根目录运行：

```powershell
python -m http.server 8080
```

打开 <http://127.0.0.1:8080/frontend/>。也可直接用浏览器打开 `frontend/index.html`，但建议使用静态服务器获得稳定的存储来源。

主要玩法在浏览器内计算。默认音乐需要网络，也可使用有权使用的本地音频。

### 启动后端和数据库存档

使用 Python 3.10 或更高版本，在仓库根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

- 游戏入口：<http://127.0.0.1:8000/play/>
- API 文档：<http://127.0.0.1:8000/docs>
- 默认数据库：当前目录的 `game.db`，启动时自动创建所需表。
- 如需原后端事件与成就种子数据，可另行运行 `python seed_database.py`；它不是统一前端或存档槽的启动前提。
- PostgreSQL 配置参考 [.env.example](.env.example) 中的 `DATABASE_URL`。基础启动不会强制连接 Redis。

当前游戏行动、剧情和考试仍由前端计算；通过 `/play/` 使用的数据库存档已接入后端。其他原型接口与前端规则并非完全相同。

## 后端接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/saves` | 列出进度槽 |
| GET / PUT / DELETE | `/api/saves/{slot}` | 读取、写入或删除第1—5槽 |
| GET | `/api/characters` | 查询人物资料 |
| GET | `/api/characters/classes` | 查询班级配置 |
| POST | `/api/characters/{id}/start` | 旧人物客户端的兼容开局接口 |
| POST | `/exam/calculate_result` | 原后端考试与排位原型 |
| POST | `/social/send_gift` | 原后端送礼与关系原型 |
| POST | `/weekend/visit_location` | 原后端周末地点原型 |
| POST | `/ng_plus/start_new_game` | 原后端遗产点与新周目原型 |
| GET | `/epilogue/stream_letter` | 逐字毕业信 |

存档接口需要 `X-Save-Token`，写入与删除使用版本号检测冲突。统一首页的开局由 `game.js` 完成，不调用旧人物开局接口。

## 项目结构

| 路径 | 内容 |
|---|---|
| `frontend/index.html` | 当前统一游戏入口 |
| `frontend/game.js`、`game.css` | 原有旅程流程和界面 |
| `frontend/roster.js`、`roster.css` | 人物、班级、换班和成长限制 |
| `frontend/journey-saves.js` | 统一旅程的本地与数据库进度槽 |
| `frontend/characters/` | 人物原始数据、前端数据、头像及早期兼容资源 |
| `docs/` | 与前端同步的 GitHub Pages 发布目录 |
| `docs/upstream/` | 上游静态快照，供对照 |
| `main.py` | FastAPI 入口及 `/play/` 静态服务 |
| `save_router.py`、`journey_model.py` | 存档接口、版本检查和统一旅程校验 |
| `character_catalog.py`、`character_router.py`、`school_catalog.py` | 后端人物及班级配置 |
| `database.py`、`models.py` | 数据库连接与模型 |
| `tests/` | 后端接口和前端规则测试 |

旧版 `app.js` 及兼容资源仍保留；当前首页运行的是 `game.js`。
