一款关于高中生活的文字养成游戏。选择你的起点，安排学习、休息、运动和社交，经历校园事件与考试，把青春写成自己的故事。

## 当前版本

**像素校园 · 学习与高考概率版（2026-10-25 更新）**：学习现在可能进步、持平或退步；久未复习增加遗忘风险。高考实际成绩由学科能力、近百天准备、身心状态和随机发挥共同决定，能力值不再直接等于考分。规则见 [学习、遗忘与考试算法](LEARNING.md)。

本次玩法调整：

- **学习有波动**：普通学习、补课和剧情学习都可能进步、持平或暂时退步，效果受学力、体力、压力和心情影响。
- **偏科会有代价**：每周仍默认 4 次行动，长期只复习一科会提高其他科目的遗忘风险；轮换与间隔复习有助于保持知识。
- **能力与考分分开**：近百天的复习投入、科目覆盖、持续性和身心状态，结合人物属性与当天随机发挥，共同决定高考实考分。
- **努力与劳逸结合更有利**：准备充分通常提高平均发挥、减少波动和失常风险，但仍保留小概率失常或超常发挥。
- **成绩与存档保留**：实际成绩结算后保存，刷新不会重新抽分；旧版已有成绩继续保留，旧档缺少的学习历史按中性处理。


河南 2025 志愿数据：已将 1220 所院校、30626 条真实专业录取记录接入五志愿模拟，其中本科 29323 条、专科 1303 条。首页同步显示本版数据数量。

打开上方试玩链接，选择人物和起点；高考出分后点击“下一页：志愿填报”，在院校目录选择“已有录取数据”，选填学校和对应专业即可模拟。已有存档可以继续使用；若页面仍显示旧版，按 Ctrl + F5 刷新。

- **轻快的首页**：晴空蓝与暖黄色、纸飞机和手账涂鸦；“开始游戏”“存档”并排居中，“设置”位于左上角。
- **像素版日常面板**：本周行动、体力压力心情、学业状态集中展示；专注学习、好好休息、运动锻炼、与人相处四张动作图直接嵌入卡片。
- **校园档案侧栏**：关系、下一件大事、最近记录和成长成就收进右侧二级界面，不再占用主界面空间。

- **个人出分喜报**：红金配色喜报仅显示当前人物的六科实际成绩和考前能力、总分及河南 2025 年参考位次，不展示其他同学的成绩。

## 怎么玩

1. 打开在线试玩。首页只保留三个入口。
2. 直接点击“开始游戏”，使用默认人物进入起点选择；也可以先打开“存档”，选择人物、查看属性，再点击“以此人物开始”。
3. 选择高一、高二、高三或 100 天，进入正式游戏与开场剧情。
4. 每周默认有 4 次行动，可以学习、休息、锻炼或与人相处；周末还可安排补课、兴趣、兼职及外出。
5. 高考结束后查看本人的出分喜报与成绩单，再点击“下一页：志愿填报”，填写最多 5 个大学与专业志愿并提交，查看独立模拟录取结果。
6. 点击游戏顶部“首页”，可返回人物存档入口，选择已有进度继续。

新故事会替换同一人物的自动存档，已有存档时会先提示确认。旧版自定义人物的当前存档仍可从存档弹窗继续；当前简洁首页不提供原版自定义创建、自由加点和开局选班面板。

## NPC 手机聊天

聊天对象为李强、苏若云和林婉儿，独立于四名可选主角。

- 在“与人相处”中选择好友，或点击好友旁的“聊聊”。
- 进入微信风格的全屏聊天场景，输入文字并发送。
- Enter 发送，Shift + Enter 换行；左上角返回游戏。
- 支持问候、学习、考试失利、进步、压力、难过、疲惫、篮球、音乐、画画、吃饭、邀约和告别等话题。
- 相同话题为不同 NPC 配置不同语气，简单追问也有对应规则；未匹配的话题会请玩家补充或换一种表达。
- 每个人物与每名 NPC 的记录分别保存，每段记录最多保留 100 条。
- 首次成功收到回复消耗 1 次行动并结算社交收益；停留在同一次聊天里继续发消息不重复扣除，离开后再次进入计作新一次社交。
- 右上角聊天设置可切换“关键词回复”和“AI 接口”。默认关键词模式无需密钥、无需联网，GitHub Pages 上也可使用。

如果旧消息因之前未配置 AI 而没有回复，在关键词模式点击“重试回复”即可接上，不会重复插入玩家消息。

### AI 接口模式的边界

当前仓库包含前端 AI 请求与错误处理逻辑，默认请求本机 `http://127.0.0.1:8787/api/chat`。这不是随在线网站提供的服务：GitHub Pages 不运行模型代理或后端，本地测试用的代理与私人配置不在本次发布范围内。

接口请求包含 NPC ID、最近 20 条对话、角色名、年级、心情、压力、关系与近期游戏日志；服务需返回 `{"reply":"NPC 回复"}`。只有切换到 AI 模式才发送该请求。密钥不应写入前端、游戏存档或提交到 GitHub。

## 高考成绩与志愿填报

高考以当前选科的六科能力为基础，结合近百天复习投入、科目覆盖、持续性、身心状态、人物学力／心态／体质和考试当天的共同波动、单科波动生成实际分数。准备充分、劳逸结合通常提高平均发挥并降低失常概率，仍可能失常或超常发挥。能力与实考分分开展示，实际六科相加得到总分，保留两位小数。成绩页采用红金喜报样式，仅展示当前人物的六科、总分和参考位次，不展示其他同学。

省位次按河南省教育考试院 2025 年一分一段表分物理类、历史类查询，显示累计人数与同分位次范围。小数总分向下取整查表，最高分段仅显示公布范围，100 分以下不推算。完整口径和原始来源见 [GAOKAO.md](GAOKAO.md)。

在成绩页点击 **“下一页：志愿填报”**，进入独立页面：

1. 按期待顺序填写 5 个“大学＋专业”位置，至少填写一项完整志愿，其余可留空；支持名称输入提示。
2. 提交后从第 1 志愿起依次检查首选类别、再选科目及 2025 年真实专业最低分，显示每项结果和官方数据来源。
3. 高于最低分按游戏规则模拟录取；同分或缺少数据时显示待定，全部不符合时显示本次模拟未录取。重复或半填志愿会提示修改。
4. 可返回成绩页或修改后重新模拟；草稿、结果与所在页面随当前人物旅程保存，修改志愿会清除旧结果。

院校目录共有 **1388 条**：教育部 2025 年全国本科名单 1365 校，补充 3 所军队院校，另选取 20 所专科。全部 39 所 985 均已收录；211 按教育部历史 112 校名单核对，将地矿油两地办学实体分别列出为 115 条（包含 985）。可按 985、211、普通本科、专科、已有录取数据筛选，搜索学校或地区，并指定填入第 1—5 志愿。

**可参与模拟录取的数据已扩展到 1220 所院校、30626 条专业记录**：普通本科 29323 条，高职专科 1303 条，覆盖 38 所非军队 985、111 个 211 办学实体。来源为河南省阳光高考信息平台公布的 2025 年分专业录取与招生计划，并保留少量已核实的高校官网记录。院校目录中的“已有录取数据”可筛选这些学校。

| 数据范围 | 数量 |
|---|---:|
| 已有普通类专业数据的院校 | 1220 |
| 普通本科专业记录 | 29323 |
| 高职专科专业记录 | 1303 |
| 按校区、医学部及原表招生名称分列的条目 | 1580 |

每条专业提供最低分、对应一分一段表的参考位次、选科要求与来源；同名但不同专业组或专业代号的专业分列，避免混用录取线。最低分参考位次不是该专业末位录取者的精确位次。压缩数据约 841 KiB，首次进入志愿页时下载，失败可重试。

**这是基于真实数据的简化游戏模拟。** 河南 2025 年实际普通本科批设置 48 个院校专业组志愿，每组 6 个专业及调剂选项；本游戏简化为 5 个“大学＋专业”，按选科、专业最低分及常规批次控制线判断，不模拟专业组投档、计划竞争、调剂、体检及单科限制。同分、缺少数据及涉及征集降分条件时待定。军队、艺体、提前批、专项、中外合作等未纳入普通类模拟；目录收录全部 985/211，不代表这些特殊招生也已实现。规则、采集口径与官方来源见 [ADMISSIONS.md](ADMISSIONS.md)，采集审计见 [data/admissions-import-audit.json](data/admissions-import-audit.json)。

## 存档与日期

身份、班级、科目能力、复习间隔、近百天记录、随机状态、已结算成绩、日期、行动点、关系、事件和聊天记录共用旅程存档。旧档从升级后开始记录，缺少的历史按中性处理，已有成绩保留。

- 自动进度：`qinghe-game-v2`。
- 按人物独立保存的最新进度：`qinghe-character-journeys-v1`。
- 新故事记录实际建档时间；旧档未记录时间时显示“旧存档未记录建档日期”，不会补造日期。
- 已有本地手动进度槽可在存档弹窗的“其他进度存档槽”展开读取。
- 原有手动槽、JSON 导入导出和数据库接口实现仍保留，但当前简洁设置面板不提供原版完整存档管理入口。

**浏览器存档不会自动跨设备或跨网址同步。** localhost 测试版与 GitHub Pages 属于不同来源，各自保存进度；换浏览器、清理站点数据或更换设备可能导致进度无法访问。

早期独立人物版本的数据不会主动删除，也不会自动转换到当前统一旅程。旧 `characters/index.html` 入口跳转到当前首页。

## 班级与成长规则

全校 7 个班，每班固定 30 人，共 210 人；其中 4 名为给定人物，206 名为固定生成的同学。

| 班级 | 选科 | 类型 |
|---|---|---|
| 2 班 | 物化生 | 尖子班 |
| 4 班 | 物化生 | 普通班 |
| 7 班 | 物化政 | 普通班 |
| 8 班 | 物化地 | 普通班 |
| 11 班 | 政史地 | 尖子班 |
| 13 班 | 政史地 | 普通班 |
| 14 班 | 史政生 | 普通班 |

游戏中点击“我的班级”查看名单或换班。换班与目标班一名生成同学交换名额，保留当前进度和能力，后续选科与考试按新班级计算。

- 语文、数学、英语将填写表百分制数值乘以 1.5，满分各 150；其他学科满分各 100。
- 六科能力为语数外加该班三门选科，上限 750；平时考试保留压力、难度、策略和随机发挥修正。
- 高考实际分数由能力基础、近百天准备和当天发挥共同生成，总分为六科实考成绩之和；个人喜报显示本人的六科成绩、总分与河南 2025 年参考位次，不展示其他同学。
- 省位次使用一分一段表累计人数，并列出同分位次范围；小数总分向下取整查表，超出公布范围不推算。规则和数据来源见 [GAOKAO.md](GAOKAO.md)。
- 普通学习、补课和剧情学习可能增加 0.15—0.5、保持不变或下降 0.05—0.25；学力和身心状态影响概率，达到上限时只增加剩余差值。每周按复习间隔和记忆稳定度抽取遗忘，小幅下降并写入日志；间隔复习提高保持能力。同周只学一科不能替代其他科目的复习。
- 小数随进度保存；负向效果与体力、压力、心情、金钱、关系按各自规则结算。
- 生成名单采用固定种子 20261017；普通班学科百分制均值 60、标准差 12，尖子班均值 75、标准差 10，截断在 0—100 范围。刷新和换班不会重新随机。

更多原始说明见 [CHARACTERS.md](CHARACTERS.md)、[SCHOOL.md](SCHOOL.md) 和 [SAVES.md](SAVES.md)；旧文档可能描述历史界面，当前用户入口以本 README 和代码为准。

## 本地运行

### 体验前端与关键词聊天

下载仓库，在根目录运行：

```powershell
python -m http.server 8080
```

打开 [本地前端](http://127.0.0.1:8080/frontend/)。关键词聊天直接在浏览器运行，不需要 API Key；本地优先读取 `frontend/music-local/` 曲库，在线版直接读取 `docs/music-local/`。也可以通过“设置 → 本地音乐库”导入或替换曲目。

### 后端与数据库

使用 Python 3.10 或更高版本：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

- 游戏：[http://127.0.0.1:8000/play/](http://127.0.0.1:8000/play/)
- API 文档：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- 默认数据库为当前目录的 `game.db`；PostgreSQL 参考 [.env.example](.env.example)。
- `/api/saves` 与 `/api/saves/{slot}` 保留 5 个进度槽及版本冲突检测，使用 `X-Save-Token` 匿名凭证。
- 其他人物、考试、社交、周末及毕业信原型接口仍保留；主要游戏计算和关键词聊天在浏览器执行。
